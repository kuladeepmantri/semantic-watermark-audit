# Security and responsible use

Maintainer: Kuladeep Mantri.

Report reproducibility defects or suspected vulnerabilities through this repository's GitHub issues when it is published. Describe the affected version, a minimal synthetic example, the expected result and the observed result. Do not post credentials, private images, personal data or unauthorized exploit material in an issue.

Use these evaluations only on assets you own or are authorized to test. The package recounts saved evidence. It does not authenticate a real-world asset, certify ownership or establish that accepted images preserve meaning. No model execution or network access is needed for the recount.
